## AI connectivity

These cases map to connection testing in **Settings → Community Plugins → I18N → `语言模型`**.

### 401 Unauthorized

The current profile key is invalid or includes whitespace. Re-enter it and test again.

### 404 Not Found

The current endpoint URL is wrong. Check whether the base URL matches the provider's API root.

### 429 Too Many Requests

The provider is rate-limiting the current account or profile. Lower `llmConcurrencyLimit` and try again.

### Timeout

Raise `llmTimeout` from the editor AI panel or switch to a faster model / provider.

### Network / SSL error

If the problem is GitHub raw-resource access, switch **综合设置 → 加速节点**. If the problem is AI connectivity, verify that the current endpoint URL is reachable.

## Extraction returns nothing

### Plugin extraction returns no rows

Plugin extraction requires a real `main.js` file in the target plugin directory. If it is missing, check the target plugin's installation, restore the missing file, and extract again. Check Regex extraction results when the source exists but AST parsing fails.

### Theme extraction returns no rows

The current theme extractor only reads `theme.css` `/* @settings */` blocks and only supports `name`, `title`, `description`, `label`, and `markdown`.

## Translation content issues

### Placeholders such as `${name}` disappeared

Search for the original row in the editor and restore the exact interpolation expressions and their order. Check brackets and escape sequences. AST translations that still contain interpolation keep the original text when their expressions do not match. Removing all interpolation can produce static text and lose dynamic values without a syntax or reload error.

### “未检测到翻译内容” or zero translation rows

Starting with 2.0.26, plugin apply requires at least one AST or Regex entry with non-empty, different source and target text. Empty dictionaries, empty rules, empty targets, or targets that all equal their sources stop the operation before backup creation, file writes, state changes, or reload.

Check that the correct translation source is active, then complete at least one effective translation in the editor before applying. Extracted rows whose targets still equal their sources do not meet this requirement.

### Backup or restoration fails

A backup creation or read failure stops the current apply before further target-file writes. Restoration requires a complete, readable backup whose recorded source version matches the current target plugin version. Unknown or different versions block restoration.

Check the reported error and the target plugin's installation and version. If the current backup is unavailable, obtain the original files for the current version from the target plugin's release channel. Confirm that the plugin can load before continuing with translation work.

### Apply reports a plugin reload failure

If the target plugin fails its test load or reload, the current implementation attempts a rollback and checks whether the original plugin can load again. Check the rollback and reload results before returning to the editor to inspect the recently edited rows.

If rollback or the subsequent reload fails, stop repeated apply attempts. Restore the target plugin's original files for its current version and confirm that it can load first.

## Installation and import

### The plugin does not appear after BRAT install

BRAT downloads files but does not auto-enable the plugin. Find **I18N** in the installed plugin list and toggle it on manually.

### Manual install does not load

Check the files in the current configuration directory. `<configDir>` defaults to `.obsidian`; replace it with the directory currently used by this vault when you use a custom configuration directory.

```text
<configDir>/plugins/i18n/
├── main.js
├── manifest.json
└── styles.css
```

The plugin folder should be named `i18n`.

### Local import fails

The Manager **管理** import action is primarily intended for Manager-exported `.i18n.gz` files. If you select a `.json`, verify that it came from an older Manager export format.

<Note>
  If these steps do not resolve the problem, open an issue in [GitHub Issues](https://github.com/obsidian-forged/i18n/issues) and include redacted developer-console errors.
</Note>
