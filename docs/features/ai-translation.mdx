AI 翻译引擎会把当前文件中符合翻译条件的条目发送给当前服务商方案，再把返回结果写回 AST、Regex 或主题编辑器。

## 支持的服务商

当前内置 16 个服务商或兼容接口配置，完整列表见 [AI 服务商配置](/configuration/ai-providers)。同一个服务商可以创建多套方案，每套方案独立保存 URL、API Key、模型和价格字段。

新建方案使用插件内置的初始配置。请在 `语言模型` 页面核对当前 URL 和模型 ID；服务商的可用模型还取决于接口和账号权限。支持刷新模型列表的接口会优先使用获取到的列表，无法获取时保留内置预设或手动输入。

<Note>
  Ollama 的默认地址是 `http://localhost:11434`。本地 Ollama 不需要 API Key；连接其他服务时按该服务的认证要求填写。
</Note>

## 费用预估

AI 面板在发送请求前显示 `预期消耗`，包含预计 Token 数和人民币费用。单价在 `语言模型` 页的当前方案中配置。

当前估算规则是：

- 开启自定义价格且 `priceInput` 大于 0 时，按该输入单价计算，单位为人民币 / 每百万 Token。
- 未启用有效的自定义输入价时，按模型名匹配内置输入价；未收录的模型使用内置默认价。
- 这是输入侧的粗略估算，不包含输出 Token 的费用，也不使用 `priceOutput`，不能作为服务商实际账单。

## 并发与批次大小

AI 面板会读取并写入这些全局设置：

- 目标语言：`language` / `llmLanguage`
- 翻译风格：`llmStyle`
- 每批条目数：`llmBatchSize`
- 并发请求数：`llmConcurrencyLimit`
- 超时时间：`llmTimeout`，单位为毫秒

新安装的默认批次大小、并发数和超时时间分别为 `10`、`3` 和 `60000`。遇到 `429 Too Many Requests` 时，可以先降低并发数，再减小批次大小。

## 默认翻译范围

默认只发送译文为空、仅含空白字符或仍等于原文的条目。开启覆盖模式后，已有译文也会重新发送。

范围由当前文件的条目和覆盖模式决定，表格搜索、筛选和行选中状态不限制 AI 批量请求。

这里复用的是当前编辑器里已有的译文，不是跨文件的本地译文缓存。另一个译文文件中的相同原文，或重置后重新进入待翻译范围的条目，仍会进入模型请求流程。

## 自定义提示词

插件内置三类提示词模板：

- AST 翻译：`llmAstPrompt`
- Regex 翻译：`llmRegexPrompt`
- 主题翻译：`llmThemePrompt`

在 **设置 → 社区插件 → I18N → 语言模型** 中修改对应模板。连接、响应格式和推理强度的设置见 [AI 服务商配置](/configuration/ai-providers)。
