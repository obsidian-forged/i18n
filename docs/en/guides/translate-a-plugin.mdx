This guide walks through translation of an installed Obsidian community plugin.

<Note>
  **Prerequisites**

  - Obsidian i18n is installed and enabled
  - the target plugin is installed and its directory contains `main.js`
  - if using AI translation, at least one provider profile is configured; targets can also be entered manually
</Note>

## End-to-end flow

<Steps>
  <Step title="Open the Manager">
    Click the globe icon, or run the command that opens the i18n panel.
  </Step>
  <Step title="Find the target plugin">
    Locate the target by name or ID in the `插件` tab.
  </Step>
  <Step title="Extract strings">
    Run `提取译文` from the plugin's more-actions menu to generate a local translation source with AST and Regex rows from `main.js`.
  </Step>
  <Step title="Open the editor and inspect rows">
    Use `前往编辑器` to open the translation. The AST table shows node type, variable name, source, and target; the Regex workspace shows Regex-extracted rows.
  </Step>
  <Step title="Open the AI panel">
    For AI translation, open the AI panel in the AST or Regex workspace. For manual translation, edit the target cells directly.
  </Step>
  <Step title="Confirm global settings">
    Check target language, style, batch size, concurrency, and timeout. A fresh installation defaults to `zh-cn`, with batch size `10`, concurrency `3`, and timeout `60000` milliseconds.
  </Step>
  <Step title="Inspect the estimate">
    Check estimated tokens and input-side cost before sending requests. See [AI translation](/en/features/ai-translation) for the calculation scope.
  </Step>
  <Step title="Translate">
    Start batch translation and wait for completion. By default, only untranslated rows are sent; overwrite mode also resends existing translations.
  </Step>
  <Step title="Review and save">
    Check placeholders such as `${variable}` and escape sequences such as `\n`, revise terminology, and save. Click `保存` when automatic saving is disabled.
  </Step>
  <Step title="Apply">
    Use `应用` in the Manager. If the interface behaves incorrectly, use `还原` first.
  </Step>
</Steps>

<Tip>
  The `未翻译` filter includes targets that are empty, whitespace-only, or still equal to their source.
</Tip>

## Add new strings after an upgrade

To add strings to an existing translation, first restore it in the Manager if it is applied, then run `增量提取` in the editor. This keeps existing targets for matching type, property name, and source text while adding newly extracted rows.

Starting in 2.0.27, recognized localization dictionaries can produce `LocalizationProperty` rows. If an existing file lacks these rows, extract or incrementally extract them, translate the new rows, save, and apply again; upgrading I18N alone does not add them to the current editor. See the [AST editor](/en/features/ast-editor) for the steps.
