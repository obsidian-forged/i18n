## AI 连接与接口问题

这些问题对应 **语言模型** 标签页里的 **测试连接**。

### 401 Unauthorized

当前 Profile 的 API Key 无效，或粘贴时带了空格。删除后重新填写，再执行一次测试。

### 404 Not Found

当前接口地址不正确。优先检查 Base URL 是否写成了服务商要求的 API 根路径。

### 429 Too Many Requests

说明当前账号触发了频率限制或额度限制。先降低 `llmConcurrencyLimit`，再重试。

### Timeout

把编辑器 AI 面板中的 `llmTimeout` 调高，或切换到响应更快的模型 / 服务商。

### Network / SSL error

如果问题发生在 GitHub 原始资源下载，先切换 **综合设置 → 加速节点**。如果问题发生在 AI 服务连接，检查当前 Base URL 是否可达。

## 提取不到内容

### 插件提取不到字符串

插件提取依赖目标插件目录里的 `main.js`。如果文件缺失，先检查目标插件安装是否完整，恢复缺失文件后再重新提取。源码存在但 AST 解析失败时，再检查 Regex 提取结果。

### 主题提取不到字符串

当前主题提取器只读取 `theme.css` 里的 `/* @settings */` 块。如果主题没有这个块，或块里没有 `name`、`title`、`description`、`label`、`markdown` 字段，就不会生成条目。

## 翻译结果问题

### 模板变量如 `${name}` 丢失

先在编辑器中搜索对应原文，逐字恢复原始插值表达式及其顺序，并检查括号和转义字符。AST 译文仍包含插值但表达式不一致时会保留原文；完全删除所有插值可以生成静态文本并丢失动态值，不一定触发语法或重载错误。

### 提示“未检测到翻译内容”或译文为 0 条

从 2.0.26 起，插件应用入口要求至少一条原文、译文均非空且不同的 AST 或 Regex 条目。空字典、空规则、空译文或所有译文仍等于原文时，会在备份、写入、状态更新和重载前中止。

请确认选中了正确的活动译文源，并在编辑器中完成至少一条有效翻译后再应用。仅有提取结果、译文仍是原文时不满足这个条件。

### 备份或还原失败

备份创建或读取失败会停止当前应用，不继续写入目标文件。还原要求备份完整可读，且记录的来源版本与当前目标插件版本一致；版本未知或不一致时会拒绝还原。

先查看错误提示并核对目标插件的安装和版本。当前备份不可用时，从目标插件的发布渠道重新获取当前版本的原始文件，确认插件能正常加载后再处理译文。

### 点击应用后提示“插件重载失败”

目标插件试运行或重载失败时，当前实现会尝试回滚，并检查原始插件能否重新加载。先查看回滚与重载结果；确认恢复成功后，再回到编辑器检查最近修改的译文行。

如果回滚或恢复后的重载仍失败，请停止重复应用，先恢复目标插件当前版本的原始文件并确认能正常加载。

## 安装与导入问题

### 用 BRAT 安装后看不到插件

BRAT 只负责下载文件，不会自动启用插件。请到已安装社区插件列表里找到 **I18N** 并手动打开。

### 手动安装后插件加载失败

请检查当前配置目录中的文件是否完整。`<configDir>` 默认是 `.obsidian`；使用自定义配置目录时，替换为该笔记库当前使用的目录。

```text
<configDir>/plugins/i18n/
├── main.js
├── manifest.json
└── styles.css
```

插件文件夹名应为 `i18n`。

### 本地导入失败

管理中心 **管理** 标签的导入入口优先对应管理导出的 `.i18n.gz` 文件。若你导入的是 `.json`，先确认它来自旧版管理导出格式。
