The AI panels send eligible entries from the current file to the active provider profile, then write the returned targets into the AST, Regex, or Theme editor.

## Providers

The plugin currently defines 16 provider or compatible-endpoint configurations. See [AI provider configuration](/en/configuration/ai-providers) for the complete list. Each provider can have multiple profiles with independently stored URL, API key, model, and pricing fields.

New profiles use the plugin's built-in initial configuration. Check the current URL and model ID in `语言模型`; available models also depend on the endpoint and account permissions. Where model-list refresh is supported, the selector prefers the fetched list and retains presets or manual input when it cannot obtain one.

<Note>
  Ollama defaults to `http://localhost:11434`. Local Ollama does not require an API key; configure other services according to their authentication requirements.
</Note>

## Cost estimate

Before sending requests, the AI panel displays `预期消耗` with estimated tokens and cost in CNY. Configure prices in the active profile on `语言模型`.

The current estimate works as follows:

- With custom pricing enabled and `priceInput` greater than zero, it uses that input rate in CNY per million tokens.
- Without a valid enabled custom input rate, it uses a built-in model input rate; unknown models fall back to the built-in default rate.
- This is a rough input-side estimate. It excludes output-token costs and does not use `priceOutput`, so it is not a provider bill.

## Batch size and concurrency

The AI panels read and write these global settings:

- target language: `language` / `llmLanguage`
- translation style: `llmStyle`
- rows per batch: `llmBatchSize`
- concurrent requests: `llmConcurrencyLimit`
- timeout in milliseconds: `llmTimeout`

For a fresh installation, batch size, concurrency, and timeout default to `10`, `3`, and `60000`. On `429 Too Many Requests`, reduce concurrency first, then reduce batch size.

## Default translation scope

By default, only rows whose target is empty, whitespace-only, or equal to the source are sent. Enabling overwrite also resends existing translations.

The current file's entries and overwrite mode determine the batch scope. Table search, filters, and row selection do not limit AI requests.

The reused content is the translation already held in the current editor, not a cross-file local translation cache. The same source in another translation file, or a reset row that becomes eligible again, still enters the model-request flow.

## Prompt templates

The plugin includes three prompt templates:

- AST translation: `llmAstPrompt`
- Regex translation: `llmRegexPrompt`
- Theme translation: `llmThemePrompt`

Edit them in **Settings → Community Plugins → I18N → `语言模型`**. See [AI provider configuration](/en/configuration/ai-providers) for connection, response-format, and reasoning-effort settings.
